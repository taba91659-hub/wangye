# 单笔删除升级

本地实现完成；尚未部署或删除生产账单。删除请求有效期15分钟，必须本人用普通记账账号登录确认页后点击删除。OAuth不能直接删除，也没有最终删除MCP工具。不支持批量删除或恢复。

1. 上传升级包内文件到仓库根目录，新分支 ledger-confirmed-deletions，创建PR核对后合并。
2. Supabase SQL编辑器执行08-confirmed-deletions.sql全文，无需替换内容。默认关闭删除功能。不要重跑01—07。
3. 用本包index.ts全文更新ledger-mcp函数并部署。Verify JWT with legacy secret保持关闭，OAuth客户端和密钥不变。
4. 确认GitHub Pages发布完成，expense-delete.html可打开。无草稿ID时应要求从ChatGPT链接进入，不能删除。
5. 执行09-enable-deletions.sql，enabled和deletions_enabled均应为true。
6. ChatGPT应用管理页点击“重新整理工具”，应增加prepare_expense_deletion、get_expense_deletion。
7. 查询一笔确实要删除的账单，明确选择后生成删除确认链接。本人核对名称、金额、分类、日期后点击删除，再检查原账本和删除状态。不要凭空删除测试记录。

保护：固定账单ID、账号和客户端隔离；保存账单快照，确认时锁定并比较当前内容，已修改或不存在时拒绝；重复点击同一请求只返回原删除结果，不影响其他账单；过期拒绝。旧新增草稿的完成记录保留，重试不会重新创建已删除的账单。请求快照在私有表保留供状态核对，并非彻底清除所有历史数据。

停用删除功能执行10-disable-deletions.sql，查询和新增独立保持可用。此开关不会恢复已经删除的账单。

自动测试涵盖权限、默认关闭、快照变化、过期、重复请求、页面显式点击和MCP参数校验。生产环境验收由本人部署后执行。
